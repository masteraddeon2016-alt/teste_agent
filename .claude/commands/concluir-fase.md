Execute o script abaixo para marcar a fase como concluída na plataforma de gerenciamento:

```bash
./scripts/notificar-fase.sh $ARGUMENTS
```

Após executar, informe ao usuário se o comando foi bem-sucedido.
Se o script retornar erro (plataforma offline), oriente o usuário a marcar
manualmente na aba Gerenciamento da plataforma.
